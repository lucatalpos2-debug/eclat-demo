Echipă

Cum își vede fiecare angajată programările în calendarul telefonului
  1. Apasă Copiază linkul la persoana respectivă și trimite-i-l.
  2. Google Calendar (pe calculator): Alte calendare → + → Din adresă URL → lipește linkul → Adaugă calendarul. Apare apoi și în aplicația de pe telefon.
  3. iPhone: Configurări → Calendar → Conturi → Adaugă un cont → Altul → Adaugă un calendar abonat → lipește linkul.
  4. Programările noi apar automat. Google actualizează calendarele abonate o dată la câteva ore; iPhone-ul, mai des.

Linkul este personal. Dacă ajunge la cine nu trebuie, apasă Link nou și cel vechi nu mai funcționează.
